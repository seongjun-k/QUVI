## 해결하려는 문제 (500자 제한, 494자)

3D프린터 값이 내려가면서 출력 대행, 시제품, 소량 생산으로 사업을 하는 소규모 사업자가 늘었습니다. 그런데 FDM 출력에서 실패는 상수입니다. 공용 출력 환경의 데스크톱 FDM 실패율은 41.1%로 조사됐고(Song & Telenko, J. Cleaner Production, 2017), 온습도와 필라멘트 상태에 따라 스파게티·워핑·레이어 분리는 잘 뽑히던 세팅에서도 나옵니다.

진짜 손실은 실패 자체가 아니라 실패를 아무도 모르는 시간입니다. 외주를 받는 개인 사업자는 프린터를 밤새 돌립니다. 새벽에 실패하면 아침까지 베드가 점유되고 프린터는 멈춰 있습니다. 하루 한 사이클이 날아가고 납기 책임은 전부 사업자가 집니다.

산업용 비전 검사 장비는 수천만 원이고 제품이 바뀔 때마다 도면과 라벨링을 다시 만들어야 합니다. 그래서 출력이 끝난 베드가 들어오면 그다음은 사람 손 없이 로봇이 출력물을 집어 검사하고 분류까지 끝내는 시스템을 60만 원대 부품으로 만들었습니다.

## QUVI (QUality VIsion)

3D프린터 출력물의 회수·검사·분류를 로봇이 사람 손 없이 처리하는 시스템입니다.
로봇팔이 출력물을 집어 검사 챔버로 옮기면 턴테이블이 4방향으로 촬영해 판정하고,
합격/불량 스테이션에 나누어 적재합니다.

출력이 끝난 베드가 들어오면 그다음부터는 사람이 개입하지 않습니다. 지금은 베드를
장착하는 한 단계만 사람이 하고 있고, 이 단계의 자동화가 다음 목표입니다.

전 과정의 실기 녹화를 [웹 데모](https://seongjun-k.github.io/QUVI/)에서 하드웨어
없이 재생해 볼 수 있습니다 (정상품/불량품 사이클 선택, 모바일 지원).

### 이 시스템에서 AI가 하는 일

AI는 사람이 규칙으로 적어 두기 어려운 두 곳에 들어갑니다.

| 어디에 | 왜 규칙으로 안 되나 | 무엇을 쓰나 |
| :--- | :--- | :--- |
| 집는 동작 | 출력물마다 위치와 모양이 달라 "어디를 어떻게 집어라"를 좌표로 정해 둘 수 없음 | 사람이 로봇팔을 직접 잡고 시연한 것을 신경망이 보고 배움 (모방학습, LeRobot ACT) |
| 불량 판정 | 결함의 종류를 미리 전부 열거할 수 없음 | 정상품이 어떻게 생겼는지 학습해 거기서 벗어난 것을 잡아냄 (이상탐지, PatchCore) |

둘 다 **불량 사진을 모아 라벨을 붙이는 작업이 필요 없습니다.** 파지는 시연 몇 회,
검사는 정상품 촬영으로 끝나 제품이 바뀌어도 다시 준비할 일이 적습니다.

### 배경

FDM 출력에서 실패는 없앨 수 있는 사고가 아니라 확률로 남는 상수입니다. 온도·습도·
필라멘트 상태가 매번 달라 숙련자와 프린트팜도 실패율을 2~8%까지 낮출 뿐 0으로
만들지는 못합니다.

| 조사 결과 | 값 |
| :--- | :--- |
| 데스크톱 FDM 출력 실패율 (공용 출력 환경) | 41.1% |
| 그중 사람 실수에서 비롯된 것 | 26.3% |
| 실패로 인한 손실까지 합친 실제 에너지 소비 | 이상 조건 대비 최대 +50% |

출처: Song & Telenko, *Material and energy loss due to human and machine error in
commercial FDM printers*, Journal of Cleaner Production, 2017.

그래서 저희가 잡은 목표는 불량을 없애는 것이 아니라 **불량을 발견하기까지 걸리는
시간을 없애는 것**입니다. 출력 대행이나 소량 생산을 하는 3D프린팅 사업자에게 손실은
검사 인건비가 아니라 프린터 가동률에서 납니다.

새벽에 출력이 실패하면 아침에 사람이 올 때까지 베드가 점유되고, 그 몇 시간이 하루치
사이클을 통째로 날립니다. 장비를 한 대 더 사는 것보다 있는 장비를 쉬지 않게 만드는
쪽이 싸다는 것이 이 시스템의 경제적 근거입니다.

산업용 비전 검사 장비는 수천만 원대이고 제품이 바뀔 때마다 도면과 라벨링 데이터를
다시 준비해야 해서, 주문마다 다른 것을 뽑는 현장에는 적용하기 어렵습니다. 그래서
재설정 비용이 거의 들지 않는 검사·분류 파이프라인을 저가 장비로 만들자고 잡았습니다.

### 설계

**파지 — 좌표 티칭 대신 모방학습.**

출력물마다 형상이 달라 고정 좌표 티칭은 제품이 바뀔 때마다 재작업이 필요합니다.
그래서 사람이 리더암을 잡고 파지를 여러 번 시연하고, 그때의 카메라 영상과 로봇
관절값 쌍을 LeRobot ACT(Action Chunking with Transformers)가 학습합니다.

학습을 마친 모델은 카메라 영상만 보고 다음 관절 동작을 스스로 만들어 냅니다. ACT는
동작을 한 스텝씩이 아니라 여러 스텝 묶음(chunk)으로 예측해 더 부드럽고 안정적으로
움직이는 모방학습 정책입니다.

덕분에 출력물 위치가 달라져도 티칭 없이 집고, 새 제품 대응이 코드 수정이 아니라
시연 몇 회로 끝납니다.

**제어 — 판단과 실시간 구동의 분리.**

상위 판단(FSM 오케스트레이터, 검사, HMI)은 PC의 ROS 2 Jazzy 노드가, 스텝 모터·조명
같은 실시간 구동은 ESP32-S3의 micro-ROS가 맡습니다.

PC 쪽 부하나 재시작이 하위 구동 타이밍을 흔들지 않고, 하위 장치는 토픽 인터페이스만
지키면 교체할 수 있습니다.

**검사 — 룰 판정 위에 ML을 보수적으로 결합.**

3D프린터 출력물에서 자주 나오는 불량은 종류가 어느 정도 정해져 있어, 지표를 정해
재는 것으로 잡을 수 있습니다.

| 불량 | 어떤 모습인가 | 무엇으로 잡는가 | 지표 |
| :--- | :--- | :--- | :--- |
| 워핑 | 바닥 모서리가 들뜨고 휘어 형상이 일그러짐 | 윤곽 일그러짐 | 컨벡스 헐 대비 윤곽 면적(Solidity) |
| 미출력·과출력 | 형상이 덜 뽑히거나 필요 이상으로 뭉침 | 크기 차이 | 기준 이미지 대비 면적비 |
| 레이어 분리 | 층 사이가 벌어져 구멍처럼 뚫림 | 구멍 (1개부터 불량) | 구멍 개수·면적비 |
| 스트링잉 | 실처럼 늘어진 잔여물이 표면에 붙음 | 표면 거칠기 | 라플라시안 텍스처 분산 |

문제는 목록에 없는 결함은 놓친다는 것입니다. 그래서 성격이 다른 두 방법을 함께 씁니다.

- **룰 판정** — 사람이 "면적이 기준보다 이만큼 모자라면 불량" 같은 잣대를 미리 정해
  두고 그대로 재는 방식. 왜 불량인지 설명할 수 있지만 적어 둔 항목만 잡습니다.
- **ML 판정(기계학습)** — 정상품 사진을 잔뜩 보여줘 "정상은 이렇게 생겼다"를 익히게
  한 뒤 벗어나면 불량으로 보는 방식. 예상 못 한 결함도 잡지만 근거 설명은 어렵습니다.

검사 오판의 비용은 비대칭입니다. 양품을 불량으로 판정하면 다시 확인하면 되지만,
불량이 양품으로 나가면 회수할 수 없습니다.

그래서 ML 쪽(PatchCore)을 도입할 때 곧바로 판정을 맡기지 않고, 결과만 기록하는
섀도우 모드로 먼저 운용했습니다. 판정은 기존 룰(위 4개 지표, 턴테이블 4방향 중
최악값 기준)이 계속 담당하고, ML 점수는 룰과의 일치율을 확인한 뒤 반영했습니다.

현재 최종 판정은 **룰과 ML을 모두 통과해야 합격**입니다. ML은 룰이 합격시킨 것을
불량으로 뒤집을 수 있지만, 룰의 불량 판정을 되돌리지는 못합니다.

판정이 엄격해지는 방향으로만 작동하므로 불량이 양품으로 유출되는 경로는 ML 도입
전보다 늘지 않습니다. ML 모델이 없는 환경에서는 룰 단독 판정으로 자동 전환됩니다.

### 개발 과정에서 해결한 문제

**학습과 추론의 단위 불일치.**

ACT 모델이 학습 데이터에서는 시연을 잘 재현하는데 실기에서는 다른 자세로 움직였습니다.
원인은 모델이 아니라 데이터 경계면이었습니다 — 학습 데이터는 라디안인데 추론 쪽은
LeRobot 정규화 값을 그대로 넘기고 있었습니다.

추론 단계에서 단위를 맞춰 해결하고 실기 구동으로 확인했습니다. 이후 학습·추론
파이프라인의 단위와 좌표계는 경계면마다 명시합니다.

**같은 시리얼 번호를 보고하는 카메라 2대.**

동일 모델 USB 카메라 2대가 같은 시리얼 번호를 보고해 장치 경로로 구분되지 않았습니다.
물리 포트 위치 기반 udev 규칙으로 매핑을 고정하고, 허브 위치가 바뀌었을 때의 복구
절차를 문서화했습니다.

### 검증 방식

- 판정·모션 변경은 실기 구동으로 확인합니다. 정상품·불량품 사이클의 실기 녹화가
  웹 데모에 올라가 있습니다.
- ACT 추론 과정은 rerun으로 관절 궤적 단위까지 시각화해 확인하며 같은 시각화를
  웹 데모에서도 볼 수 있습니다.
- 로봇이 실제로 움직이는 시스템이므로 HMI에 비상정지를 두고 검사 ML처럼 오판
  여지가 있는 요소는 검증 기간을 거친 뒤에만 판정에 반영합니다.
- 2026년 4월부터의 커밋을 시행착오까지 포함해 전부 공개 이력으로 남겼습니다.

### 한계와 계획

남은 한계는 두 가지입니다.

- **베드를 사람이 넣어야 합니다.**
- **룰 판정이 기준 이미지 1장에 의존합니다.** 다만 같은 제품을 반복 출력하는 소량
  생산에서는 그 이미지가 곧 정답이라 제약이 되지 않습니다.

다음 목표는 검사 자동화가 아니라 **출력–회수–검사–재출력이 사람 없이 도는 무인
루프**입니다. 세 가지를 붙이면 닫힙니다.

| 붙일 것 | 어떻게 |
| :--- | :--- |
| 베드 착탈 | 같은 자리·같은 궤적의 반복이라 로봇팔이 아니라 지금 레일에 쓰는 수준의 전담 기구로 됩니다 |
| 재출력 지시 | 검사에서 나온 불량 개수를 프린터 공개 API(OctoPrint·Moonraker)로 그대로 넘깁니다 |
| 불량품 회수 | 걸러낸 것을 분쇄해 필라멘트로 되돌립니다 |

그러면 사람이 하는 일은 필라멘트 보충과 완성품 회수만 남습니다.

하드웨어 확장으로는 탑뷰 카메라(파지 정확도), 자석식 툴체인저(그리퍼 자동 교체),
접근 감지 정지(비상정지에 더한 안전층)를 계획하고 있습니다.

### 요약

- 목표 사용자는 출력 대행·시제품·소량 생산을 하는 3D프린팅 사업자입니다. 절약되는 것은
  검사 인건비가 아니라 **실패를 발견할 때까지 프린터가 멈춰 있는 시간**이고, 60만
  원대 부품비는 프린터 한 대 값 수준이라 장비 증설과 직접 비교됩니다.
- **파지·이송·검사·분류 전 구간이 실제 하드웨어에서 동작**하며 실기 녹화 기반 웹

  늘어날 수 있는 방향을 구조적으로 막았습니다.
- 파지는 시연 수집으로, 검사는 정상품 학습으로 대응하므로 제품이 바뀌어도 코드와
  라벨링을 다시 만들지 않습니다.

신청서 본문에 쓴 수치의 출처. 심사 AI는 외부 링크를 열람하지 않으므로 본문에는
저자·연도까지만 넣고 상세는 여기에 둔다. 인터뷰에서 되물을 가능성이 높은 항목이다.

| 인용 수치 | 출처 | 비고 |
| :--- | :--- | :--- |
| 데스크톱 FDM 출력 실패율 41.1%, 그중 사람 실수 기인 26.3%, 실패 포함 시 실제 에너지 소비가 이상 조건 대비 최대 +50% | Ruoyu Song, Cassandra Telenko, *Material and energy loss due to human and machine error in commercial FDM printers*, **Journal of Cleaner Production**, 2017 | 본문에서 유일하게 저자·저널명을 명시한 인용. 오픈 스튜디오(공용 출력 환경) 측정치 |

| 프린터 원격 제어 REST API | OctoPrint API, Klipper/Moonraker API | 향후 계획의 "출력 작업 자동 재투입"이 신규 개발이 아니라 통합 작업이라는 근거 |

**인터뷰 대비 예상 반론**

- *"41.1%는 공용 스튜디오 수치인데 사업자에게도 해당되나"* — 해당 수치는 상한이고, 숙련자·프린트팜도 2~8%로 0이 아니다. 핵심 주장은 실패율의 크기가 아니라 **밤샘 무인 가동에서 1회 실패의 대기 비용**이라는 점.
- *"재활용은 어디까지 구현했나"* — 미구현. 불량품이 한 곳에 모이는 분류 단계까지가 전제 조건 충족이며 분쇄·압출은 계획 단계라고 그대로 답한다.
- *"베드 착탈이 제일 어려운 것 아닌가"* — 매번 같은 자리·같은 궤적이라 학습이 필요 없다. 임의 형상 출력물 파지보다 난도가 낮고, 자석식 시트는 이미 대부분의 프린터가 채택하고 있다.
